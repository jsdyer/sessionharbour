Supported formats and encrypted Chrome sessions

JSON exports containing tabs/windows or bookmark trees are supported, including Firefox session JSON (the selected navigation per tab). Closed Firefox tabs are excluded. Bookmark HTML and one-URL-per-line text are portable choices.

Unencrypted Chromium SNSS versions 1 and 3 can recover tab titles and navigation URLs. This is not a complete browser-profile restore. Encrypted versions, including OS-bound version 5, cannot be decrypted here. Use the original browser to export bookmarks or use the optional local tab exporter in this repository.
